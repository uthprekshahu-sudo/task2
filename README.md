# Task 2: Intermediate HTML, CSS, and JavaScript

A single-page project demonstrating form validation, responsive layouts, and DOM manipulation.

## 📋 Objective
Enhance HTML and CSS skills, and learn JavaScript for DOM manipulation.

## 🛠️ Built With
- **HTML** – contact form, responsive content sections, to-do list structure
- **CSS** – Flexbox navbar, CSS Grid layout, media queries for responsiveness
- **JavaScript** – form validation and dynamic DOM manipulation

## 📁 Files
- `index.html` – page structure for all sections
- `style.css` – styling, Flexbox/Grid layout, and media queries
- `script.js` – form validation logic and to-do list functionality

## ✨ Features

### 1. Contact Form
A form with fields for name, email, phone, and message, styled with CSS.

### 2. JavaScript Form Validation
- Checks that all required fields are filled
- Validates email format
- Validates a 10-digit phone number
- Shows inline error messages until corrected

### 3. Responsive Layout
- Flexbox-based navigation bar that adapts to smaller screens
- CSS Grid content section that reflows from 3 columns → 2 → 1 based on screen size
- Media queries for tablet and mobile breakpoints

### 4. Dynamic To-Do List
- Add new tasks
- Click a task to mark it complete (strikethrough)
- Delete tasks dynamically using JavaScript DOM manipulation

## 🚀 How to View
1. Clone or download this repository
2. Open `index.html` in any web browser (or use the live GitHub Pages link once enabled)
